# MyLandry - SaaS Laundry Satuan

Multi-tenant SaaS platform for per-item laundry operations.
Domain: laundry.gampangin.web.id

## Tech Stack
- Next.js 16 App Router + React 19 + TypeScript
- Tailwind CSS v4 (light-only)
- Prisma 7 + PostgreSQL
- iron-session 8
- TanStack Query, Zod, Radix UI
- Vitest for testing

## Getting Started
```bash
npm install
npx prisma migrate dev
npm run dev
```
